# ชุดดาวน์โหลดล่วงหน้าสำหรับ workshop Program Landscape

> English: see [README.md](README.md)

ชุดนี้ช่วยดาวน์โหลดส่วนที่มีขนาดใหญ่ของการติดตั้ง **ก่อน** วันอบรม ได้แก่
แพ็กเกจ npm ทั้งหมด (~430 MB) และ Docker image ทั้งหมด (~1.2 GB)
ในวันอบรมท่านจะได้รับซอร์สโค้ด และขั้นตอนติดตั้งจะใช้ไฟล์ที่อยู่ในเครื่องแล้ว
แทนการดาวน์โหลดผ่านเครือข่ายของห้องอบรม

ชุดนี้ไม่มีโค้ดของแอป มีเพียงรายการแพ็กเกจที่ใช้ (`pnpm-lock.yaml`)
และไฟล์สำหรับสร้าง Docker image สามตัว (`infra/`)

**สิ่งที่ต้องมี:** อินเทอร์เน็ตสำหรับดาวน์โหลดประมาณ 2 GB พื้นที่ว่างประมาณ 7 GB และเวลา 20–60 นาที

## 1. ติดตั้งเครื่องมือ

- **Windows:** WSL2 พร้อม Ubuntu และ Docker Desktop ที่เปิด *WSL integration*
  ให้ Ubuntu แล้ว ทำทุกขั้นตอนด้านล่าง **ในเทอร์มินัล Ubuntu**
- **macOS หรือ Linux:** Docker พร้อม Compose v2
- **ทุกระบบ:** Node.js 24.22.1 ขึ้นไป แล้วสั่ง `corepack enable` หนึ่งครั้ง

## 2. แตกไฟล์ชุดนี้ในโฟลเดอร์ home ของ Linux

เก็บชุดนี้ และโปรเจกต์ที่จะได้รับในวันอบรม ไว้ในโฟลเดอร์ home ของ Linux (`~`)
บน Windows **ห้าม** วางไว้ใต้ `/mnt/c/...` เพราะ pnpm แยกที่เก็บไฟล์ดาวน์โหลดตามดิสก์
ไฟล์ที่ดาวน์โหลดลงดิสก์ Windows จะใช้กับโปรเจกต์บนดิสก์ Linux ไม่ได้

```bash
cd ~
tar -xzf /path/to/program-landscape-prefetch.tar.gz
cd program-landscape-prefetch
```

บน Windows โฟลเดอร์ Downloads อยู่ที่ `/mnt/c/Users/<ชื่อผู้ใช้ Windows>/Downloads/`

## 3. ล็อกอิน Docker Hub (แนะนำ)

```bash
docker login
```

บัญชี Docker Hub แบบฟรีช่วยให้ไม่ติดขีดจำกัดการดาวน์โหลดแบบไม่ล็อกอิน
ซึ่งทุกคนที่ใช้เครือข่ายมหาวิทยาลัยเดียวกันใช้โควตาร่วมกัน

## 4. รันการดาวน์โหลดล่วงหน้า

```bash
node prefetch.mjs
```

สคริปต์จะตรวจเครื่องมือ ดาวน์โหลดแพ็กเกจ สร้างและดึง Docker image
แล้วแสดงรายการเครื่องหมายถูกเมื่อเสร็จ หากมีขั้นตอนใดล้มเหลว
ให้แก้ตามที่สคริปต์แนะนำแล้วรันใหม่ ส่วนที่ดาวน์โหลดเสร็จแล้วจะไม่ต้องโหลดซ้ำ

ตรวจภายหลังว่าทุกอย่างยังอยู่ครบ:

```bash
node prefetch.mjs --check
```

## ระหว่างรอวันอบรม

- **เก็บ** ไฟล์ที่ดาวน์โหลดไว้ อย่าสั่ง `pnpm store prune` หรือ `docker system prune -a`
- **อย่า** สั่ง `docker compose up` ในโฟลเดอร์ของชุดนี้
- ลบโฟลเดอร์ชุดนี้ได้ ไฟล์ที่ดาวน์โหลดเก็บอยู่นอกโฟลเดอร์
- ในวันอบรม ให้ clone โปรเจกต์ไว้ในโฟลเดอร์ home ของ Linux เช่นกัน
  (เช่น `~/program-landscape`) และใช้บัญชีผู้ใช้เดียวกัน บน Windows ใช้ Ubuntu ตัวเดิม
