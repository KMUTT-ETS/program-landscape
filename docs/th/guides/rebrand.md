# การปรับแบรนด์และ UI

> **English:** [English version](../../guides/rebrand.md)

**ผลลัพธ์** ท่านแทนเครื่องหมายและสีของ มข. ด้วยของสถาบันท่านได้ ตามที่สัญญาอนุญาตกำหนด

## ระบบ token

design token เก็บเป็น **ค่าสามตัวแบบ OKLCH** ใน `packages/design/src/css/tokens.css` แยกขอบเขตด้วย `[data-theme='light']` และ `[data-theme='dark']` โดยมี utility ของ Tailwind ครอบไว้ ตัวปรับความโปร่งใสจึงใช้ได้ (`bg-surface-1/80`)

`packages/design/src/tailwind-preset.ts` **แทนที่** สเกลสี ระยะห่าง ความมน ขนาดตัวอักษร และเงาของ Tailwind ไม่ใช่ขยายเพิ่ม `bg-slate-500` จึงเป็น error ตอนคอมไพล์โดยตั้งใจ นอกจากนี้ ESLint ยังห้ามเขียนค่าสีฐานสิบหกตรง ๆ และห้ามเรียก `rgb()`/`oklch()` ด้วยตัวเลขดิบ ผ่านกฎ `no-restricted-syntax` ใน `eslint.config.mjs` ส่วนการเขียนครอบตัวแปร CSS นั้นอนุญาต

การสลับธีมใช้แอตทริบิวต์ `data-theme` ไม่ใช่คลาส `dark` ผ่าน `next-themes` ที่ตั้งค่าให้ปลอดภัยกับ SSR หน้าจึงไม่กะพริบเป็นธีมผิดตอนโหลด

**การตั้งชื่อ token สำคัญกว่าที่เห็น** ธรรมเนียมคือ `--color-<family>-default` ไม่ใช่ `--color-<family>` เปล่า ๆ ชื่อผิดจะไม่มีค่าสำรองให้ — จะเรนเดอร์เป็นกล่องดำใน SVG หรือดำสนิทใน HTML grep `tokens.css` ก่อนจะตั้งชื่อ token ขึ้นมาเอง เรื่องที่เกี่ยวข้องกัน: ใน SVG ให้ลงสี `<text>` ผ่านแอตทริบิวต์ `fill=` ไม่ใช่ `style.fill`

## รายการตรวจสอบการปรับแบรนด์

| สินทรัพย์ | Path |
|---|---|
| โลโก้ ทั้งโหมดสว่างและโหมดมืด | `apps/web/public/brand/kku-logo-light.png`, `kku-logo-dark.png` |
| Favicon | `apps/web/app/icon.png` — สร้างใหม่ด้วย `pnpm tsx scripts/build-favicon.ts` หลังเปลี่ยนโลโก้ |
| สีหลักของแบรนด์ | `packages/design/src/tokens/color.ts` → `brandCardinal` (`default` / `hover` / `subtle`) |
| ฟอนต์ | `apps/web/app/layout.tsx` มีไฟล์ Sarabun สำรองในเครื่องที่ `apps/web/public/fonts/sarabun/` สำหรับเครือข่ายที่เข้า Google Fonts ไม่ได้ |

**มีไฟล์ราว 101 ไฟล์ใต้ `apps/web` (`.ts`/`.tsx`) ที่อ้างถึง "KKU" หรือ "Khon Kaen"** มากกว่าที่คาดไว้ และรวมถึงข้อความบนหน้าจอ ข้อความสถานะว่าง ส่วนหัวเทมเพลต PDF ข้อความ system prompt ของ AI และคอมเมนต์ ให้วางแผนกวาดทั้งชุดอย่างตั้งใจ และทำ *ตั้งแต่เนิ่น ๆ* ก่อนจะเขียนโค้ดของตัวเองทับลงไป diff จะได้ยังตรวจทานไหว

พิจารณาเปลี่ยนชื่อ token `brand-cardinal` เป็นชื่อกลาง ๆ อย่าง `brand-primary` เป็นการปรับแบรนด์ขั้นแรก จะทำให้ทุกการตัดสินใจเรื่องสีหลังจากนั้นไม่ผูกกับสถาบันใด ตอนนี้ยังเป็นแค่การค้นหา-แทนที่แบบกลไก ถ้าปล่อยไว้จะกลายเป็นงานขุดกรุ

## ชื่อผลิตภัณฑ์

ชื่อที่เป็นทางการคือ **"Program Landscape — KKU Curriculum Intelligence Platform"** (ชื่อย่อ: *Program Landscape*) มีชื่อเก่าสามชื่อที่เลิกใช้แล้วและถูกกวาดออกจากข้อความที่ผู้ใช้เห็นไปหมดแล้ว ได้แก่ *Curriculum Compass* กับ *ทักษทัศน์* (ทั้งคู่เป็นชื่อรหัสภายในเดิม โดยชื่อหลังไม่ใช่คำไทยที่มีความหมายจริง) และ *KKU Curriculum Landscape* (ชื่อเดิมของผลิตภัณฑ์) ให้ถือว่าทั้งสามชื่อตายแล้ว ถ้าเจอในคอมเมนต์หรือใน prompt เก่าใต้ `prompts/` ปล่อยไว้ในฐานะบันทึกทางประวัติศาสตร์ได้ แต่ห้ามให้โผล่ถึงผู้ใช้ ข้อความภาษาไทยไม่แปลชื่อผลิตภัณฑ์ แต่ใช้ชื่อภาษาอังกฤษห่อไว้ในวลีนามภาษาไทย เช่น *แพลตฟอร์ม Program Landscape*
