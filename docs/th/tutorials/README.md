# บทเรียนสำหรับสถาบันผู้นำไปใช้

> **English:** [`README.md`](../../tutorials/README.md)

บทเรียนแบบทีละขั้นสำหรับมหาวิทยาลัยที่นำระบบไปใช้ แต่ละบทระบุหน้า แฟ้ม และปุ่มที่ต้องใช้อย่างชัดเจน พร้อมบอกว่าหลังทำแต่ละขั้นควรเห็นอะไร

| ลำดับ | บทเรียน | ผลลัพธ์ |
|---|---|---|
| 1 | [Getting started](./getting-started.md) | แอปทำงานบนเครื่องแล็ปท็อปของท่าน และลงชื่อเข้าใช้ด้วยผู้ดูแลระบบคนแรกแล้ว |
| 2 | [Get Program Deep-Dive working](./program-deep-dive.md) | `/programs/<id>` แสดงเนื้อหาจริงของหลักสูตรหนึ่งหลักสูตร และแท็บ Setup checklist เป็นสีเขียว |
| 3 | [นำเข้าข้อมูลจาก API (ฝึกปฏิบัติ)](./load-data-from-an-api.md) | connector ที่ท่านเขียนเองเติมชุดข้อมูล Enrolment จาก HTTP API จำลอง อยู่คู่กับแฟ้มที่อัปโหลด |
| 4 | [Workshop: ติดตั้งและใช้งาน Program Deep-Dive](../workshop/README.md) | workshop ภาคปฏิบัติ 1.5 วัน: งานเตรียมการ หนึ่งหน้าต่อหนึ่ง session หน้าการแก้ปัญหา และคู่มือผู้จัด |
| ขั้นสูง (ไม่บังคับ) | [Adapt the registrar connector](../../tutorials/adapt-the-registrar-connector.md) | ตัวอย่างของ KKU: connector ของงานทะเบียนอ่านระบบข้อมูลนักศึกษาโดยตรง (มีเฉพาะฉบับภาษาอังกฤษ) |
