# คู่มือผู้จัด

> **English:** [`facilitator.md`](../../workshop/facilitator.md)

สำหรับผู้ดำเนินการ workshop 1.5 วัน ผู้เข้าร่วมทำตามหน้าของแต่ละ session บนแล็ปท็อปของตนเอง
หน้าที่ของท่านคือทำให้ทุกคนเดินหน้าต่อได้ และช่วยผู้ที่ตามไม่ทัน

## ก่อนวันอบรม

1. **สองสัปดาห์ก่อน:** ส่งลิงก์ [ก่อนวันอบรม](./00-before-the-day.md) ให้ผู้เข้าร่วมทุกคน
   และขอให้ตอบกลับด้วยผลลัพธ์จากส่วนสุดท้าย "ตรวจสอบความพร้อม"
2. **หนึ่งสัปดาห์ก่อน:** ติดตามผู้ที่ยังไม่ตอบ แล็ปท็อปที่ยังไม่ได้รัน `pnpm setup` ที่บ้าน
   จะใช้เวลาช่วงเช้าดาวน์โหลดผ่านเครือข่ายของห้องอบรม และแล็ปท็อปที่มหาวิทยาลัยดูแลมักบล็อก WSL2 หรือ Docker
   ให้ตรวจสอบตั้งแต่ตอนนี้ ไม่ใช่ในวันอบรม
3. **ไม่กี่วันก่อน:** เริ่ม opencode พิมพ์ `/models` และยืนยันว่ายังมี model ฟรี รายการ model ฟรีเปลี่ยนบ่อย
4. **ไม่กี่วันก่อน:** ทำ session 1, 2, 3 และ 6 ด้วยตนเองบนฐานข้อมูลใหม่กับ `main` ล่าสุด
   และจดเวลาที่ pipeline ใช้และค่าใช้จ่าย
5. เตรียม **AI key สำรอง** ที่จำกัดวงเงินไว้ (ดูด้านล่าง) และข้อมูลรับรองของ KMITL หากสถาบันของท่านมี
6. ขอให้ผู้เข้าร่วมเส้นทางข้อมูลจริงนำแฟ้มที่ลบข้อมูลส่วนบุคคลออกแล้วมา ห้ามรับแฟ้มที่มีเลขประจำตัวประชาชนหรือวันเกิด

## ห้องอบรมและเครือข่าย

- ไฟฟ้าสำหรับแล็ปท็อปทุกเครื่องตลอดทั้งวัน
- การเข้าถึงอินเทอร์เน็ตไปยัง host เหล่านี้ ส่งรายการให้ทีมเครือข่ายล่วงหน้า:

| Host | ใช้สำหรับ |
|---|---|
| `generativelanguage.googleapis.com` | Google Gemini (pipeline, embedding) |
| `openrouter.ai` | OpenRouter หากใช้ |
| `population.un.org` | connector `un-wpp` |
| `www.mytcas.com`, `assets.mytcas.com` | connector `tcas` เส้นทางข้อมูลจริง |
| `api.openalex.org` | connector `openalex-works` เส้นทางข้อมูลจริง |
| `skill.kmitl.ac.th` | `kmitl-skill-mapping` หากใช้ |
| `opencode.ai` | opencode และ model ฟรี |
| `github.com` | ดึง `main` ล่าสุด |

Docker image และแพ็กเกจดาวน์โหลดในงานเตรียมการ ไม่ใช่ในห้องอบรม หากงานเตรียมการของผู้เข้าร่วมล้มเหลว
จะต้องเข้าถึง `registry.npmjs.org`, `registry-1.docker.io` และ `deb.debian.org` ด้วย
และต้องดาวน์โหลดประมาณ 6 GB

## ขั้นตอนที่ใช้เวลานานและการจัดเวลา

- **pipeline** ใช้เวลาประมาณ 20 ถึง 25 นาทีต่อหลักสูตร และค่าใช้จ่ายประมาณ USD 0.40 ถึง 0.80
  ตรวจสอบว่าผู้เข้าร่วมทุกคนเริ่ม pipeline ก่อนพักช่วงบ่ายของวันที่ 1
- **`un-wpp`** ดาวน์โหลดประมาณ 68 MB แล็ปท็อปยี่สิบเครื่องเริ่มพร้อมกันคือประมาณ 1.4 GB
  ผ่านเครือข่ายของห้อง หากเครือข่ายช้าให้เริ่มทีละโต๊ะ
- **`pnpm skills:normalise --source=linkedin --auto-promote`** ใช้เวลาประมาณหนึ่งชั่วโมง
  และจำเป็นเฉพาะเมื่อมีข้อมูลรับรองของ KMITL หากมี ให้รันบนเครื่องของท่านก่อนเพื่อรู้เวลา
  และให้ผู้เข้าร่วมเริ่มเป็นอย่างแรกใน session 3
- **Google key แบบฟรี** embed ข้อความรายวิชาได้ประมาณ 1,000 รายการต่อวัน หลักสูตรตัวอย่างใช้น้อยกว่านั้นมาก
  ผู้เข้าร่วมที่รันหลักสูตรขนาดใหญ่ของตนเองด้วยอาจถึงขีดจำกัด ส่วน overlap จะใช้เพียงรหัสวิชาที่ใช้ร่วมกัน
  ซึ่งเพียงพอสำหรับ workshop

## หลังวันอบรม

- ลบ key สำรองที่ให้ยืม
- เตือนผู้เข้าร่วมเส้นทางข้อมูลจริงว่าแล็ปท็อปของตนมีข้อมูลของมหาวิทยาลัยอยู่ ให้ลบด้วย "Start over"
  ที่หน้าของแต่ละชุดข้อมูล หรือลบฐานข้อมูลพร้อมกับระบบทั้งหมด เว้นแต่สถาบันอนุมัติให้เก็บไว้
- รวบรวมสิ่งที่ผิดพลาดแล้วส่งให้ผู้ดูแลโครงการ เพื่อแก้ไขหน้าเหล่านี้ก่อน workshop ครั้งต่อไป
