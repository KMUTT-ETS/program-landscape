# Workshop: ติดตั้งและใช้งาน Program Deep-Dive

> **English:** [`README.md`](../../workshop/README.md)

workshop ภาคปฏิบัติ 1.5 วัน สำหรับเจ้าหน้าที่ IT ของมหาวิทยาลัยที่นำ Program
Landscape ไปใช้ เริ่มจากโน้ตบุ๊กที่ยังไม่ได้ติดตั้งอะไร และจบด้วย Program Deep-Dive
ที่ทำงานอยู่บนเครื่องของท่าน ใช้หน้าเหล่านี้ในห้องอบรมทีละขั้น หรือทำเองภายหลังก็ได้
ทุกหน้าใช้ได้โดยไม่ต้องมีผู้จัดคอยช่วย

## สำหรับใคร

เจ้าหน้าที่ IT ที่คุ้นเคยกับ terminal และการเขียนโค้ด แต่ยังไม่เคยเห็นโค้ดของระบบนี้
ไม่จำเป็นต้องรู้จักตัวระบบมาก่อน

## สิ่งที่ท่านจะได้เมื่อจบ

- ระบบที่ทำงานอยู่บนโน้ตบุ๊กของท่าน โดยท่านเข้าระบบในฐานะผู้ดูแลระบบ
- Deep-Dive ของหลักสูตรตัวอย่างที่แสดงเนื้อหาจริง คำนวณด้วย pipeline จริงและ AI key ของท่านเอง
- หากเตรียมแฟ้มข้อมูลของมหาวิทยาลัยตนเองมา: ผลแบบเดียวกันสำหรับหลักสูตรหนึ่งของท่าน
- connector และการวิเคราะห์ใหม่บน Deep-Dive ที่ท่านเขียนเองด้วยความช่วยเหลือของ AI coding assistant

## สองเส้นทาง

**เส้นทางข้อมูลตัวอย่าง (ทุกคน)** นำเข้าแฟ้มของมหาวิทยาลัยสมมติ Workshop Demo
University (มหาวิทยาลัยสาธิตเวิร์กช็อป) จาก `workshop/sample-data/` ใน repository
ทุกบุคคลและทุกตัวเลขในแฟ้มเป็นข้อมูลสมมติ แต่ยังต้องรัน pipeline จริง จึงต้องมี AI key ที่ใช้งานได้

**เส้นทางข้อมูลจริง (ไม่บังคับ)** หากเตรียมแฟ้มส่งออกของมหาวิทยาลัยตนเองไว้ล่วงหน้า
ให้นำเข้าหลังจบเส้นทางข้อมูลตัวอย่าง ด้วยขั้นตอนเดียวกัน ลบข้อมูลส่วนบุคคลออกก่อน:
ไม่มีเลขประจำตัวประชาชน ไม่มีวันเกิด
