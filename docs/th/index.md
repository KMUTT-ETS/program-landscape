Program Landscape เป็นระบบสนับสนุนการตัดสินใจสำหรับสภามหาวิทยาลัย ระบบให้คะแนนหลักสูตรตามความต้องการ การเงิน คุณภาพ และทักษะในอนาคต และตัวเลขทุกตัวระบุแหล่งที่มา ความสดใหม่ และรุ่นของระเบียบวิธี

หน้าภาษาไทยในเว็บไซต์นี้ครอบคลุมคู่มือผู้นำไปใช้ บทเรียน และเวิร์กช็อป หน้าอื่น ๆ มีเฉพาะ[ฉบับภาษาอังกฤษ](../index.md)
