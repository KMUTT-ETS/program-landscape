# แจ้งล่วงหน้า: เริ่มเตรียมตัวสัปดาห์นี้

> **English:** [`early-notice.md`](./early-notice.md)

ทีมของท่านได้รับการยืนยันเข้าร่วม workshop AIUI วันที่ **23–24 พฤศจิกายน**
บุคลากร IT เข้าร่วมทั้งสองวัน ผู้บริหารเข้าร่วมในวันที่สอง ก่อนหน้านั้นมี
**การประชุมเตรียมความพร้อมออนไลน์วันที่ 16 พฤศจิกายน** และต้องส่ง
**แบบฟอร์มความพร้อมภายในวันที่ 19 พฤศจิกายน เวลา 18:00 น.**

เมื่อจบ workshop แต่ละทีมจะสาธิต Program Deep-Dive ของ **หลักสูตรหนึ่งของมหาวิทยาลัยท่านเอง**
ที่ทำงานบนแล็ปท็อปพร้อมข้อมูล หากมีเวลา ให้สาธิตการวิเคราะห์เพิ่มเติมที่ทีมสร้างเองด้วย

การเตรียมบางส่วนต้องรอหน่วยงานอื่น จึงควรเริ่มตั้งแต่สัปดาห์นี้

## สัปดาห์นี้

1. **เลือกหนึ่งหลักสูตร** ที่ผู้บริหารให้ความสำคัญ และหาไฟล์ PDF เล่มหลักสูตรได้
2. **ขอข้อมูลจากเจ้าของข้อมูลตั้งแต่วันนี้** (งานทะเบียน งานบุคคล งานการเงิน
   หน่วยงานที่ทำแบบสำรวจบัณฑิต) ทั้งข้อมูลส่งออกของหลักสูตรนั้นและ PDF เล่มหลักสูตรฉบับปัจจุบัน
   รายการชุดข้อมูลและคอลัมน์อยู่ใน [การนำเข้าข้อมูลจาก spreadsheet](../data-import.th.md)
   การขอข้อมูลจากหน่วยงานอื่นอาจใช้เวลาหลายวัน
3. **ตรวจแล็ปท็อป** ต้องมีหน่วยความจำ 16 GB ดิสก์ว่าง 25 GB และสิทธิ์ติดตั้ง WSL2 กับ Docker
   แล็ปท็อปที่มหาวิทยาลัยดูแลมักบล็อกไว้ ดู [การติดตั้งบน Windows ด้วย WSL2](../guides/windows-wsl2.th.md)
   หากเครื่องของท่านติดข้อจำกัด ให้จัดหาเครื่องอื่นตั้งแต่ตอนนี้

เริ่มติดตั้งได้ทันทีตามหน้า [ก่อนวันอบรม](./00-before-the-day.th.md)

## เลือกเส้นทางข้อมูล

| เส้นทาง | สิ่งที่ต้องนำมา |
|---|---|
| **A. ข้อมูลจริง** | ข้อมูลส่งออกของหลักสูตรที่ลบข้อมูลส่วนบุคคลแล้ว และ PDF เล่มหลักสูตร |
| **B. ผสม** | ข้อมูลส่งออกเท่าที่ได้มา ส่วนที่ขาดให้ตัวสร้างข้อมูลจำลองเติมให้ |
| **C. จำลอง** | เฉพาะ PDF เล่มหลักสูตร ตัวสร้างข้อมูลจะเขียนทุกไฟล์ให้สำหรับมหาวิทยาลัยของท่าน |

ทั้งสามเส้นทางไปถึงการสาธิตแบบเดียวกัน หากขอข้อมูลไม่ทัน ให้เลือก C
ซึ่งเป็นเส้นทางที่สมบูรณ์ ไม่ใช่ความล้มเหลว วิธีใช้ตัวสร้างข้อมูลอยู่ใน
[Session 3](./03-university-data.th.md#ไม่มีแฟ้มส่งออก-สร้างชุดข้อมูลจำลองสำหรับมหาวิทยาลัยของท่าน)
ในการสาธิต ท่านจะต้องบอกว่าข้อมูลส่วนใดเป็นข้อมูลจริงและส่วนใดเป็นข้อมูลจำลอง

## ข้อมูลส่วนบุคคล

ลบข้อมูลส่วนบุคคลออกก่อนนำไฟล์ออกจากหน่วยงาน:

- ไม่มีเลขประจำตัวประชาชนหรือเลขหนังสือเดินทาง
- ไม่มีวันเกิด ที่อยู่ เบอร์โทรศัพท์ หรืออีเมลส่วนตัว
- ไม่มีชื่อคู่กับรหัสนักศึกษาหรือรหัสบุคลากร

ไฟล์ที่มีเลขประจำตัวประชาชนหรือวันเกิดจะถูกปฏิเสธในห้องอบรม
