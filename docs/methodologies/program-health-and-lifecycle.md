## Why it was retired

This file was declared the canonical source that the in-app page mirrored, but
the page is what was actually maintained. By 2026-09-13 this file had drifted
to document version 1.0 (2026-05-07) and `health-score.v3.4` — thirteen
methodology versions behind, with no Risk Management section — while the page
was current. Keeping two ~50 KB copies in sync by hand is what produced the
drift, so there is now one copy.
